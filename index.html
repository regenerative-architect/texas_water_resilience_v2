Commons identity & multiplayer

Pseudonymous by design. Local-room mode synchronizes only same-origin tabs/windows in this browser profile. Cross-device mode requires the included server.js relay or another compatible endpoint.

Hosted PWA companion files

This standalone file works without a server. Service workers do not work under file://. When deployed via HTTPS or localhost, generate these optional companions and place them beside index.html.

Storage contract

Structured projects, profiles, plans and notes use IndexedDB. Lightweight preferences use localStorage. Imports are size-limited, parsed defensively, and accepted only when their schema marker matches this app. SHA-256 demonstrates file integrity, not authorship or provenance.

Security guidance for hosting

Keep the standalone core free of secrets; render untrusted text as text, not HTML; validate JSON schemas and file sizes; serve with HTTPS; and add a restrictive Content Security Policy appropriate to your hosting. A starting policy for this dependency-free build is default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; connect-src 'self' https://www.drought.gov https://www.twdb.texas.gov;. Tighten it further when scripts/styles are split into separate files.

Zero-Harm / Anti-Inversion: This platform exists to increase resilience, stewardship, cooperation and evidence-based decisions—not to encourage unsafe water practices, bypass public-health requirements, undermine lawful water rights or present speculative technology as proven.
